## Repository Structure & Project Directory

This repository contains two primary programming projects exploring fundamental concepts in programming language design, including scope resolution, variable binding, L-values/R-values, block-scope minimization, and dynamic vs. lexical scoping.

```text
PROGRAMMING-LANGUAGES-ASSIGNMENTS/
│
├── Names_Bindings_Scopes-C/
│   ├── water_billing_simulator.c             # C implementation for water consumption billing
│   └── README.md                             # System documentation & C execution links
│   
└── Dynamic-Scope-Analysis-Lua/
    ├── patient_triage_execution_system.lua        # Lua script demonstrating lexical vs. dynamic scope
    └── README.md                                  # Scope analysis documentation & Lua execution links
```
